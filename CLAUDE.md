# Compta Ltd

## Frontend Design Skill

This project uses the **taste-skill** (anti-slop frontend framework) for all UI/frontend work.

### When to apply taste-skill

The skill at `.claude/skills/taste-skill.md` MUST be read and followed whenever:
- Building or modifying any frontend page, component, or UI
- Creating landing pages, portfolios, marketing pages, or redesigns
- Making design decisions (typography, color, layout, motion, spacing)
- Reviewing frontend code for design quality

### Quick reference

- Always start with a **Design Read** before generating UI code
- Set the **Three Dials** (DESIGN_VARIANCE, MOTION_INTENSITY, VISUAL_DENSITY) based on the brief
- Run the **Pre-Flight Check** (Section 14) before shipping any frontend work
- Zero em-dashes, no AI tells, no slop defaults

### Out of scope for taste-skill

Dashboards, data tables, admin panels, multi-step forms, code editors - use appropriate design systems directly for those.
